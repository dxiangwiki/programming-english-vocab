
# programming-english-vocab
> 同一个英文单词，区分日常英语含义 和 编程领域含义，支持页面内搜索。

## ✨ 功能
- 单词分为三类：
  - A：英文原义与编程含义完全不同
  - B：语义有联系，但含义存在偏移（大量编程语言关键字）
  - C：编程含义基本和英文本义一致
- 内置搜索框，输入单词快速检索
- 移动端自适应，手机电脑都能正常浏览

## 📖 使用方法
1. 打开网页
2. 在顶部搜索框输入单词，例如：`if`、`int`、`for`、`switch`
3. 表格自动过滤匹配的词汇
